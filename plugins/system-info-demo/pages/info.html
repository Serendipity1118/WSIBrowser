端末とアプリの情報

アプリでしか取れない情報の API を 1 つずつ呼び、戻り値をそのまま表示します。

端末 device

device.key はこのプラグイン専用です。2 回押して同じ値になること、別のプラグインでは違う値になることを確認します。


  


  

    
アプリと言語 app locale

    
権限を宣言しなくても使えます。

    

      
      
    

    

  


  

    
位置情報 location

    
未決定なら getCurrent / request で OS の許可ダイアログが出ます。位置情報を OFF にすると getCurrent はエラーになります。

    

      
      
      
    

    

      
      
      
    

    

  


  

    
ネットワーク network

    
「変化を監視」を ON にして機内モードや Wi-Fi を切り替えると、届いた変化が新しい順に表示されます。

    

      
      
    

    

  


  

    
バッテリー battery

    
「変化を監視」を ON にして充電ケーブルを抜き差しすると、充電状態の変化が届きます (残量だけの変化は届きません)。

    

      
      
    

    

  


  

    
生体認証 biometrics

    
ダイアログの先頭にプラグイン名が付きます。キャンセルしてもエラーにならず、success: false と reason が返ります。
