WSI Browser is a web browser that runs extensions you bring yourself.

On a desktop browser, extensions let you reshape a page however you like. Phone browsers have no such mechanism. WSI Browser loads "plugins" packaged as ZIP files and runs each one only on the sites it declares.

What it does

- Works as an ordinary browser, with tabs, history, bookmarks, search and downloads.
- Once a plugin is loaded, its JavaScript and CSS run only on the sites the plugin declares.
- A plugin can carry its own settings screen, reachable from the app menu.
- Plugins can be enabled or disabled one at a time, and removed whenever you want.

Loading a plugin

Pick a file, enter a URL, scan a QR code, or share one in from another app. Before anything is installed you see the plugin's name, author, target sites and the permissions it asks for. Read that screen before you continue.

About permissions

A plugin can only use what it declared up front. Beyond the basics such as storage, network access and page manipulation, anything that touches stored credentials, files, device information, the clipboard, tab control or navigation control needs your explicit consent at install time. The app refuses calls you did not consent to.

The target sites are declared by the plugin as well. On any other site the plugin does nothing at all.

Where plugins come from

No plugins ship with this app. You choose and load your own. The format and the authoring guide are published for developers.

Who it is for

- People who want pages to work the way they want on a phone, not only on a desktop.
- People who repeat the same steps on a site and would rather shorten them.
- Developers who want to write and try their own plugins.

Please note

Plugins are supplied by you, not by us. What a plugin contains is up to whoever published it. Only load plugins from a source you trust.
