WSI Browser は、自分で用意した拡張機能を読み込めるウェブブラウザです。

パソコンのブラウザでは拡張機能で好きなようにページへ手を入れられますが、スマートフォンのブラウザにはその仕組みがありません。WSI Browser は ZIP 形式の「プラグイン」を読み込み、プラグインが宣言したサイトでだけ動かします。

■ できること

・ふつうのブラウザとして使えます。タブ、履歴、ブックマーク、検索、ダウンロードに対応しています。
・プラグインを読み込むと、宣言されたサイトでだけ JavaScript と CSS が動きます。
・プラグインごとに設定画面を持たせられます。アプリ内のメニューから開けます。
・プラグインは個別に有効と無効を切り替えられ、いつでも削除できます。

■ プラグインの読み込み方

ファイルを選ぶ、URL を指定する、QR コードを読み取る、他のアプリから共有する、のいずれかで読み込めます。読み込む前に、プラグインの名前、作者、対象サイト、必要な権限が一覧で表示されます。内容を確認してから読み込んでください。

■ 権限の考え方

プラグインは、あらかじめ宣言した権限の範囲でしか動けません。保存領域、通信、ページの操作といった基本的なものに加えて、ログイン情報の保管、ファイル、端末の情報、現在地、クリップボード、タブ操作、ページ遷移の制御は、読み込むときに利用者の同意が必要です。現在地はさらに OS の許可が必要で、アプリを使っている間だけ取得します。生体認証を使うプラグインが受け取るのは本人確認の成否だけです。同意していない機能はアプリ側が拒否します。

対象サイトもプラグインが宣言します。宣言していないサイトでは何も動きません。

■ プラグインはどこから来るのか

このアプリにはプラグインが同梱されていません。利用者が自分で選んで読み込みます。開発者向けの作成手順と仕様は公開しています。

■ こんな方に

・スマートフォンでも自分用にページを使いやすくしたい方
・よく使うサイトの操作を短くしたい方
・自分でプラグインを書いて試したい方

■ 注意

プラグインは利用者が持ち込むものです。どのような内容が含まれるかは提供元によります。信頼できる提供元のものだけを読み込んでください。
