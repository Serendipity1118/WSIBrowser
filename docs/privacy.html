プライバシーポリシー

WSI Browser／最終更新日 2026年9月13日

WSI Browser (以下「本アプリ」) は、Serendipity (以下「当方」) が提供するウェブブラウザです。利用者がプラグインを読み込むことで、特定のサイトに機能を追加できます。このページでは、本アプリと、本アプリ上で動くプラグインが情報をどう扱うかを説明します。

  • 当方は個人情報を収集しませんアカウント、広告、アナリティクス、クラッシュレポートの仕組みはありません。
  • データは端末の中に残ります閲覧データ、プラグインの設定や保存データは当方へ送信されません。
  • プラグインへの提供は同意の範囲だけ位置情報や端末の識別子などは、読み込み時の同意や OS の許可がなければプラグインに渡りません。
  • 生体情報は誰にも渡りません顔や指紋のデータは OS が処理し、本アプリもプラグインも本人確認の成否だけを受け取ります。

1. 当方が収集する情報

当方は、本アプリの利用者から個人情報を収集しません。

  • アカウント登録やログインはありません。
  • 広告用の識別子は取得しません。広告 SDK を組み込んでいません。
  • 利用状況の分析ツール (アナリティクス、クラッシュレポート) を組み込んでいません。
  • 位置情報、端末の識別子、生体認証の結果などを当方のサーバーへ送る処理はありません。

2. 端末に保存される情報

次の情報は利用者の端末内にのみ保存され、当方へは送信されません。

  • ウェブサイトの Cookie、ローカルストレージ、キャッシュ、タブ内の閲覧履歴など、ブラウザが通常保持するデータ
  • 読み込んだプラグインの本体と、プラグインごとの設定および保存データ
  • プラグインが保管したログイン情報 (iOS は Keychain、Android は Keystore で暗号化して保存)
  • プラグインごとの端末キーを作るための値 (iOS は Keychain に保存)
  • 本アプリ自体の設定

これらは本アプリを端末から削除すると消えます。ただし iOS の Keychain に保存された値は、OS の仕様によりアプリを削除しても残ることがあります。Cookie は本アプリの設定画面から消去でき、プラグインのデータはプラグインを削除すると消えます。

設定画面の「バックアップ」で書き出したファイルは、利用者が指定したパスワードで暗号化され、利用者が選んだ保存先に置かれます。当方へは送信されません。

3. 通信先

本アプリはブラウザなので、利用者が開いたウェブサイトへ通信します。その通信内容と、各サイトによる情報の取り扱いは、それぞれのサイトの運営者に属します。

これに加えて、読み込まれたプラグインに関して次の通信が発生することがあります。

  • プラグインが従うべき設定値 (ポリシー) の取得と、プラグインの更新有無の確認。通信先はプラグインの製作者が指定したもので、当方のサーバーとは限りません。
  • プラグイン自身が行う通信。プラグインは、許可された範囲で製作者のサーバーなどへ通信することがあります。

プラグインを 1 つも読み込んでいない場合、これらの通信は発生しません。

当方のサーバーが受け取るのは、要求されたプラグインの識別子と、通信に伴ってサーバーへ自動的に届く技術的な情報 (IP アドレスなど) です。閲覧履歴や入力内容を受け取ることはありません。

4. プラグインについて

プラグインは利用者自身が選んで読み込むものです。本アプリにプラグインは同梱されておらず、当方はプラグインの配布も推奨も行いません。

プラグインは、読み込む前に提示される対象サイトと権限の範囲でのみ動作します。権限はプラグインの一覧画面でいつでも確認でき、プラグインを無効化または削除すると以後は利用されません。

5. 端末の機能の利用

  • ネットワーク: ウェブページとプラグインの読み込みに使います。
  • カメラ・マイク: プラグインを QR コードから読み込むとき、およびウェブページのファイル選択で写真や動画を撮るときに使います。QR コードの読み取りは端末内で処理されます。
  • 写真・ファイル: ファイルのダウンロード、ウェブページやプラグインでのファイル選択、ファイルからのプラグインの読み込み、バックアップに使います。
  • 位置情報: 位置情報の権限を持つプラグインが現在地を求めたときにだけ使います。初回は OS の許可ダイアログが表示されます。
  • Face ID・指紋: 生体認証の権限を持つプラグインが本人確認を求めたときにだけ使います。

これらは該当する操作や要求があったときにのみ利用し、常時取得することはありません。位置情報、カメラ、写真などの許可は、端末の設定アプリからいつでも取り消せます。

6. 子どもの利用

本アプリは子どもを対象としていません。当方は個人情報を収集しないため、子どもから個人情報を取得することもありません。

7. 本ポリシーの変更

内容を変更する場合は、このページを更新し、最終更新日を改めます。

Privacy Policy

WSI Browser / Last updated 13 September 2026

WSI Browser ("the app") is a web browser provided by Serendipity ("we"). By loading plugins, users can add features to specific sites. This page explains how the app, and the plugins running in it, handle information.

  • We collect no personal informationThere is no account, advertising, analytics or crash reporting.
  • Your data stays on your deviceBrowsing data and plugin settings or stored data are never sent to us.
  • Plugins get only what you allowedLocation, device identifiers and similar data reach a plugin only with your consent at install time or the OS permission.
  • Biometric data is never sharedFace and fingerprint data are handled by the OS; the app and plugins only learn whether verification succeeded.

1. What we collect

We do not collect personal information from users of the app.

  • There is no account and no sign-in.
  • We do not read advertising identifiers. There is no advertising SDK.
  • There is no analytics or crash-reporting SDK.
  • Nothing in the app sends your location, device identifiers or biometric results to our servers.

2. What stays on your device

The following is stored only on your device and is never sent to us.

  • Cookies, local storage, cache, the history within a tab and the other data a browser normally keeps for a site
  • The plugins you loaded, together with their settings and stored data
  • Sign-in details a plugin saved (encrypted in the iOS Keychain or the Android Keystore)
  • The value used to derive per-plugin device keys (kept in the Keychain on iOS)
  • The app's own settings

All of it is removed when you uninstall the app, except that values in the iOS Keychain may remain after uninstalling because of how iOS works. Cookies can be cleared from the app's settings, and a plugin's data is removed when you delete the plugin.

A backup exported from the settings screen is encrypted with a password you choose and saved where you choose. It is not sent to us.

3. Where the app connects

The app is a browser, so it connects to the websites you open. What those sites do with your information is governed by their own operators.

In addition, loaded plugins may cause the following connections.

  • Reading policy values a plugin must obey and checking whether a newer version of that plugin exists. These URLs are chosen by the plugin's author and are not necessarily ours.
  • Requests the plugin itself makes, within its permissions, for example to its author's server.

With no plugin loaded, none of these connections happen.

What our own server receives is the identifier of the plugin being requested, plus the technical information any server receives with a request, such as an IP address. It does not receive your browsing history or anything you type.

4. About plugins

Plugins are chosen and loaded by you. None ship with the app, and we neither distribute nor endorse any plugin.

A plugin runs only within the target sites and permissions shown to you before you install it. You can review its permissions in the plugin list at any time, and a disabled or deleted plugin can no longer use them.

5. Device capabilities

  • Network: to load web pages and plugins.
  • Camera and microphone: when you load a plugin by scanning a QR code, and when a web page's file picker takes a photo or video. QR codes are processed on the device.
  • Photos and files: for downloads, file pickers in web pages and plugins, loading a plugin from a file, and backups.
  • Location: only when a plugin with the location permission asks for the current position. The OS asks you the first time.
  • Face ID and fingerprint: only when a plugin with the biometrics permission asks to verify you.

Each is used only for the action or request in question, never continuously. You can revoke location, camera, photo and other permissions in the device's Settings app at any time.

6. Children

The app is not directed at children. Since we collect no personal information, we do not collect it from children either.
